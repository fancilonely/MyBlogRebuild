# 关于本站

这是一份基于 **Astro** 与开源主题 **Shirone** 构建的个人博客示例站点。

## ✦ 这里有什么

- **文章**：长文写作、笔记与阅读记录。
- **说说**：碎片化的日常动态。
- **归档**：按时间、分类与标签浏览全部内容。

## ✦ 站点说明

- 本站由 [Astro](https://astro.build/) 静态构建，基于开源主题 [Shirone](https://github.com/LyraVoid/Shirone) 二次开发，遵循 **Material 3 Expressive** 设计语言。
- 内容以 Markdown + Git 管理，构建产物为纯静态文件，可部署到任意静态托管服务。
- 本站不提供评论、登录或在线后台。

## ✦ 替换成你自己的内容

1. 在 `src/content/posts/`、`src/content/moments/` 下新增或编辑 Markdown 文件（默认已被 `.gitignore` 隔离）；
2. 在 `src/config/` 中修改站点信息、作者资料与导航；
3. 本文件是仓库中唯一保留的「关于」示例，可直接改写成你自己的介绍。
